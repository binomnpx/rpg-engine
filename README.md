This is my [RPG](https://en.wikipedia.org/wiki/Role-playing_game) passion project made real. It is entirely written in Lua and is designed for the [PICO-8](https://www.lexaloffle.com/pico-8.php) fantasy console. 

The motivation for creating my own RPG began sometime around 2020. In search of the perfect game, I decided to make my own.



This project serves more as a prototype as I refine the game's systems and design. It has allowed me to explore more mature software development practices such as software architecture design, object-oriented programming, and the src-include paradigm.

![Here are some things you can do in the game](https://github.com/binomnpx/rpg-engine/main_20260818_145008.gif)

What you see is the result of a sprinkle of procedural generation, a fully fleshed out entity-component-system architecture, and some painstaking art made by yours truly. Some objects even "talk" to each other in the code. This game programming pattern makes debugging and feature creep more manageable!
